# Ledger Sample (no devfile, on purpose)

This project deliberately has **no** `devfile.yaml`. It is the starting point for
act 5 of the demo, where the devfile is authored live in front of the audience.

`docs/DEVFILE-LIVE-BUILD.md` has the exact keystrokes, the finished file, and a
short talk track for each block, so the segment can be run cold.
